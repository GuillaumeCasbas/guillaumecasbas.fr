# Avant de remettre le contrôle dans vos livraisons, j'ai livré.

Plus de 10 ans de développement web et mobile, dont 4 ans comme lead tech. Je sais ce que c'est qu'une mise en prod qui part de travers, parce que je suis passé par là. Voici le détail.

**Backend** : PHP, Symfony, Go, PostgreSQL, GraphQL, Algolia

**Frontend** : TypeScript, React, React Native, Next.js, Bootstrap, Tailwind, Storybook

**DevOps** : Docker, GCP, CI/CD, Nginx, tests automatisés

**CMS** : PrestaShop, WordPress, Drupal, Strapi

**Transversal** : TDD, clean architecture, mentoring, SOLID, YAGNI, KISS

## Expériences professionnelles

### Synergie : développeur web et mobile

*Novembre 2025 à juillet 2026*

**Contexte** : intégration de l'IT de Medelse, entité rachetée, dans le système d'information de Synergie, avec l'adaptation des solutions existantes au nouveau métier.

**Missions**

- Mise à jour complète des librairies des projets React Native et React
- Reprise du développement de l'application mobile (React Native, Jest) pour aligner les fonctionnalités sur les besoins métier de Synergie
- Maintenance et amélioration des applications React existantes
- Modifications du backend Symfony pour prendre en charge les nouveaux cas d'usage
- Peer programming et passation du code à l'équipe interne pour assurer la pérennité des projets

**Stack** : React Native, React, Jest, Symfony, GraphQL

### Réflex Boutique : développeur web

*Mars 2025 à juillet 2026*

**Contexte** : une entreprise qui gère toute son activité sur PrestaShop (vente en ligne et physique, devis, logistique, stocks), avec de nombreux modules spécifiques développés en Symfony.

**Missions**

- Développement de modules métier sur mesure : connecteur aux API des transporteurs, calcul des meilleures ventes, gestion comptable
- Vérification et optimisation des tournées de livraison par camion
- Gestion avancée des stocks : suivi en temps réel, alertes
- Travail en binôme avec le développeur interne

**Stack** : PrestaShop, Symfony, PHP, API tierces

### Développeur web et mobile indépendant

*Depuis janvier 2025*

**Contexte** : des interventions pour des indépendants, des agences web et des TPE/PME, sur des besoins courts et ciblés.

**Missions**

- Support et conseil technique : mises à jour de sécurité, migrations de sites, gestion de DNS, résolution de bugs
- Développement de nouvelles fonctionnalités sur des sites existants
- Développement de modules spécifiques pour CMS

**Stack** : WordPress, PrestaShop

### Medelse : lead tech, développeur full-stack

*Septembre 2020 à novembre 2024*

**Contexte** : une plateforme de mise en relation pour lutter contre la pénurie de soignants et faciliter les remplacements des praticiens de santé. Back-office, espaces web et application mobile, utilisés par plus de 5 000 utilisateurs actifs. En quatre ans, aucune interruption de service.

**Missions**

- Montée en compétence des équipes : formation et accompagnement sur les bonnes pratiques craft (SOLID, TDD, YAGNI, KISS)
- Mise en place d'une politique de tests automatisés : PHPUnit, Jest, Storybook
- Conception et développement de l'application mobile en React Native (Jest, Detox)
- Développement des espaces web : applications statiques en React (Jest, Cypress)
- Développement du back-office métier complet en Symfony (Messenger, PostgreSQL, PHPUnit)
- Conception et maintenance d'une API Symfony et GraphQL pour les applications web et mobile
- Innovation produit : MVP en Go pour tester de nouveaux marchés

**Stack** : Symfony, Docker, CI/CD, Storybook, React, React Native, Go, PostgreSQL, GraphQL, PHPUnit, Jest, Cypress, Detox

### Human's Connexion : développeur full-stack

*Avril 2015 à mai 2020*

**Contexte** : une agence web généraliste aux projets variés (sites vitrines, SaaS, objets connectés), pour des clients allant des TPE/PME aux grandes entreprises européennes et au secteur de la défense.

**Missions**

- Développement sur mesure pour CMS : modules et thèmes spécifiques pour Drupal, WordPress et PrestaShop
- Intégration et maintenance de sites web : migration, optimisation, support technique
- Développement d'outils SaaS : solutions métier en Laravel et Symfony, interfaces en React et Vue.js, déployées avec Docker
- Applications mobiles Android natives en Java et Kotlin

**Stack** : Laravel, Symfony, PHP, React, Vue.js, WordPress, Drupal, PrestaShop, Docker, Java, Kotlin
